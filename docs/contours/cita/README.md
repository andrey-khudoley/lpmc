# CITA — индекс участка

## Что такое CITA

CITA — Contract Integration Task Agent. Один из четырёх контуров системы (LINA, PACT,
MITA, CITA). По архитектуре отвечает за выполнение задач через опубликованные
API-контракты внешних систем; не отвечает за выбор того, что и когда выполнять (это
PACT). Три контура из четырёх — агентные структуры с однотипными именами на `-TA`
(MITA, CITA); PACT назван иначе не только по раскрытию, но и по форме — он не агент.
MITA и CITA — родственники одного уровня (исполнители), различающиеся первой буквой
имени (модальность исполнения) при общем суффиксе `-TA` (принадлежность к
исполнителям); граница между ними по архитектуре проходит по наличию у целевой
системы пригодного опубликованного контракта, а не по предметной области.
(Источник расшифровки и осмысления имени — CONTOURS.md §2, §2.1; это единственное
обращение этого документа к спецификации, за принципиально неизменными вещами.)

### `docs/spec/spec.md` — желаемое состояние

Один файл, полная спецификация контура: назначение и границы, место в
четырёхконтурной схеме, критерий модальности MITA/CITA, обязательные инварианты,
контракты входа («авторизованная задача») и выхода, номенклатура событий, сетевая
модель, отношение к секретам, реестр интеграций и формат описания интеграции,
идемпотентность и повторная доставка, типизированные ошибки, необратимые операции,
верификация результата, порядок переезда возможности MITA → CITA, инструментарий
исполнителя, кандидаты на первые интеграции, наблюдаемость и журналирование,
этапность, открытые вопросы, перечень источников. Описывает то, чего сегодня не
существует; за фактами о текущем состоянии сюда обращаться нельзя.
