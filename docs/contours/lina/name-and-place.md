# Имя контура и его место в общей схеме

## Что это за страница

Правило документооборота (`/tmp/vds-kz-pipeline/research/allocation.md` §6, п. 2)
запрещает страницам `docs/` (кроме `docs/spec/` и `docs/adr/`) ссылаться на
спецификацию за данными о поведении системы. Единственное исключение сделано
для **принципиально неизменных вещей**: расшифровки имени контура и его места
в общей схеме контуров доверия. Эта страница — то самое исключение и ничего
сверх него: здесь нет ни слова о том, что LINA будет уметь, как она будет
устроена или что из этого реализовано. За текущим состоянием — в
`docs/current-state.md` и `docs/README.md`; за целевым устройством — в
`docs/spec/spec.md`.

## Имя

**LINA** — сокращение от **Linguistic Interface Agent**. Раскрытие
зафиксировано решением D-002 общесистемного уровня
(`second-system/DECISIONS.md`, статус в источнике «принято») и не подлежит
пересмотру без отдельного архитектурного решения; для контура lina это
дублирует ADR `docs/adr/0002-imya-kontura-lina.md`.

## Один из четырёх контуров

Система разрезана на четыре функциональных контура (`second-system/CONTOURS.md`
§2):

| Контур | Расшифровка | Отвечает за | Не отвечает за |
|---|---|---|---|
| **LINA** | Linguistic Interface Agent | Диалог с человеком, сбор и обогащение запроса до полноты, возврат одобренного результата в чат | Состояние задачи, полномочия, исполнение |
| **PACT** | Policy, Authorization & Control Tier | Маршрутизацию, авторизацию, реестр и состояния задач, проверку исходящего результата | Разговор с пользователем, выполнение действий |
| **MITA** | Manual Interaction Task Agent | Выполнение задач через веб-интерфейсы там, где API отсутствует | Выбор того, что и когда выполнять |
| **CITA** | Contract Integration Task Agent | Выполнение задач через подготовленные API-интеграции | Выбор того, что и когда выполнять |

(Таблица дословно воспроизводит `second-system/CONTOURS.md` §2.)

## Недоверенный контур, граница проходит по PACT

Функциональных контуров четыре, контуров доверия — два, и граница между ними
проходит по PACT (`second-system/CONTOURS.md` §3.2):

```text
недоверенный          арбитр            привилегированные
    LINA        →      PACT        →      MITA / CITA
    LINA        ←      PACT        ←      MITA / CITA
```

- LINA обрабатывает внешний недоверенный ввод и не имеет полномочий.
- MITA и CITA обладают доступом к внешним системам и не принимают решений.
- PACT стоит между ними и является единственным арбитром.

Это свойство двустороннее (`second-system/CONTOURS.md` §3.3): «не существует
пути от внешнего сообщения к привилегированному исполнителю и обратно,
минующего PACT». Прямой путь — от LINA к PACT — проверяет допустимость
исполнения. Обратный путь — от PACT к LINA — проверяет допустимость
раскрытия результата пользователю: результат исполнения может содержать
фрагменты страниц, ответы API, тексты ошибок и содержимое файлов, часть
которых не предназначена внешнему каналу. Отсюда прямое следствие для LINA:
она не имеет прямого исходящего доступа к MITA/CITA и не получает результат
исполнения напрямую от них — только то, что уже прошло проверку PACT.
