## Четыре контура

| | Расшифровка | Отвечает за |
|---|---|---|
| **LINA** | Linguistic Interface Agent | диалог с человеком, сбор запроса до полноты, возврат результата |
| **PACT** | Policy, Authorization & Control Tier | маршрутизацию, авторизацию, реестр задач, проверку исходящего |
| **MITA** | Manual Interaction Task Agent | исполнение через веб-интерфейсы там, где нет API |
| **CITA** | Contract Integration Task Agent | исполнение через подготовленные API-интеграции |

Контуров доверия два: недоверенный (LINA) и привилегированный (MITA, CITA). PACT стоит на границе и является точкой сужения в обе стороны.

```
недоверенный          арбитр            привилегированные
    LINA        →      PACT        →      MITA / CITA
    LINA        ←      PACT        ←      MITA / CITA
```

## Ключевое правило

> **LLM выбирает маршрут, но не выбирает полномочия.**

Компонент, выдающий полномочия, детерминирован. Обоснование — `DECISIONS.md` D-003.
