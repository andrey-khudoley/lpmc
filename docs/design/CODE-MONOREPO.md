# LPMC — Lina, Pact, Mita, Cita

Код системы. Проектные документы — уровнем выше: `ROADMAP.md` (волны сборки),
`vds-kz-*/docs/spec/spec.md` (спецификации контуров), `cloud-vds-admin/second-system/DECISIONS.md`
(журнал решений). Узел, на котором это работает, разворачивается ролью `lpmc_system`
в репозитории инфраструктуры.

Язык — TypeScript на Node (D-025). Монорепозиторий: контракты общие для всех контуров,
и согласовывать их версии между отдельными репозиториями было бы работой, которой можно
не заводить.

## Пакеты

- `packages/contracts` — то, о чём контуры договорились и что не принадлежит ни одному
  из них: закрытые перечни, имена событий, схемы. Меняется только вместе с решением.

## Негативные тесты

Тесты пишутся **до** реализации (пункт `P1-CHK-04` роадмапа). Негативный тест проверяет,
что запрещённое получает отказ; написанный после кода, он обычно проверяет лишь то,
что код и так делает.
