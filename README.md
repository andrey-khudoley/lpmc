# LPMC — единый репозиторий системы

Четыре контура — **L**ina, **P**act, **M**ita, **C**ita — их код, документация и
развёртывание в одном месте. Цель раскладки: `git clone` → собираемая и
разворачиваемая система, без хождения по нескольким репозиториям.

## Раскладка

```
packages/     код (npm workspaces, TypeScript/Node): контуры, общие contracts/runtime/executor,
              egress-proxy, human-view и tui — интерактивный диалог с системой
docs/
  design/     сквозные решения системы: DECISIONS, SPECIFICATION, CONTOURS, STAGE-0 …
              и CODE-MONOREPO.md — почему код собран монорепозиторием
  contours/   спеки и ADR по каждому контуру: lina / pact / mita / cita
deploy/       развёртывание узла: рабочая роль lpmc_system + playbook (см. deploy/README.md)
ROADMAP.md    волны сборки
```

## Сборка и проверка

```bash
npm ci            # зависимости workspaces
npm run build     # сборка пакетов в порядке зависимостей
npm test          # включая негативные тесты (пишутся ДО реализации, P1-CHK-04)
```

## Диалог с системой

После развёртывания с системой разговаривают через **TUI** — интерактивный
интерфейс контура LINA: обращение, уточняющие вопросы и ответы на них, результат,
приёмка — весь цикл в одном окне.

```bash
lpmc-tui          # диалог с Линой (обёртка ставится ролью lpmc_system)
```

Один разговор проходит через все четыре контура: сообщение → **LINA** уточняет и
собирает запрос до полноты → **PACT** авторизует и выдаёт исполнителю сессию →
**MITA** (веб-интерфейсы) или **CITA** (API-интеграции) исполняет → результат
возвращается в диалог после egress-проверки PACT. TUI при этом остаётся в
недоверенном контуре: он видит только одобренные ответы, не реестр задач арбитра.
Команды, переменные и пример полного цикла — `packages/tui/README.md`.

## Границы: чего в репозитории нет — намеренно

- **Секретов** — ключей, `storage_state`, паролей, allowlist с учётными данными.
  Они живут вне репозитория и вне резервных копий (ROADMAP; ADR-0011/0012 MITA).
  «Готовая система» = собираемая и разворачиваемая; секреты подаются отдельно.
- **`node_modules/` и `dist/`** — восстанавливаются из `package-lock.json` и `tsc`.
- **Общих серверных ролей** (nginx, nftables, base_system, admin_panel …) — они
  общие с другими проектами и подключаются из инфра-репозитория, а не дублируются.

## История

Репозиторий собран как «новый старт»: содержимое перенесено копированием из
прежних мест (`lpmc-system`, доки контуров `vds-kz-*`, `cloud-vds-admin/second-system`),
история отдельных репозиториев в него не переносилась.
